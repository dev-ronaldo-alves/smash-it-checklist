# Smash It - Fechamento de Loja | Checklist Diário

## Descrição

O Smash It é uma aplicação web simples e intuitiva projetada para auxiliar no processo de fechamento de loja, garantindo que todas as tarefas diárias sejam concluídas de forma eficiente. Ele oferece um checklist interativo, a capacidade de anexar fotos para documentação e um sistema de partilha de relatórios via WhatsApp, tornando a comunicação e a supervisão mais fáceis.

## Funcionalidades

*   **Checklist Diário Interativo:** Marque as tarefas concluídas com facilidade.
*   **Gestão de Fotos:** Anexe até 8 fotos para cada fechamento de loja, ideal para documentar o estado da loja ou tarefas específicas.
*   **Partilha via WhatsApp:** Gere um relatório formatado com o progresso do checklist, nome do responsável, observações e número de fotos, e partilhe diretamente via WhatsApp.
*   **Modo Escuro/Claro:** Alternância entre temas para uma melhor experiência visual.
*   **Persistência de Dados:** As tarefas e fotos são guardadas localmente no navegador, garantindo que o progessão não seja perdido ao recarregar a página.
*   **Responsividade:** Design adaptável para funcionar bem em dispositivos móveis e desktops.

## Tecnologias Utilizadas

*   **HTML5:** Estrutura base da aplicação.
*   **CSS3 (Tailwind CSS):** Estilização e design responsivo.
*   **JavaScript:** Lógica interativa, gestão do checklist, manipulação de fotos e integração com a API Web Share.
*   **Font Awesome:** Ícones para melhorar a interface do utilizador.

## Como Usar

1.  **Aceder à Aplicação:** Abra o ficheiro `index.html` num navegador web.
2.  **Preencher o Checklist:** Marque as tarefas à medida que as conclui.
3.  **Anexar Fotos:** Utilize o botão de adicionar fotos para carregar imagens da galeria ou tirar fotos diretamente com a câmara.
4.  **Adicionar Observações:** Insira quaisquer notas ou observações relevantes no campo designado.
5.  **Partilhar Relatório:** Clique no botão "Partilhar no WhatsApp" para enviar um resumo do checklist, incluindo fotos (se suportado pelo dispositivo), para os contactos desejados.
6.  **Alternar Tema:** Use o ícone de sol/lua no cabeçalho para mudar entre o modo claro e escuro.
